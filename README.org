* Dotfiles

A collection of configuration files managed with GNU Stow.

** Prerequisites

See =deps.txt= for required tools. [[https://www.gnu.org/software/stow/][GNU Stow]] is the only hard dependency.

*** Gnu Stow

GNU Stow is a symlink farm manager. See the [[https://www.gnu.org/software/stow/][official docs]] for details.

** Usage

A =.stowrc= file at the root configures stow defaults:

#+begin_src sh
  --target=~
  --dir=~/.dotfiles
  --no-folding
#+end_src

- =--target=~= — symlinks are created in =~=
- =--dir=~/.dotfiles= — package root is =~/.dotfiles=
- =--no-folding= — real directories are always created, never directory symlinks. Required because multiple packages contribute to shared directories like =~/.config/= and =~/.local/bin/=

Stow picks up =.stowrc= automatically when invoked from =~/.dotfiles=. To make it work from *any* directory, symlink it to =~=:

#+begin_src sh
  ln -s ~/.dotfiles/.stowrc ~/.stowrc
#+end_src

To stow a package:

#+begin_src sh
  stow emacs
#+end_src

To stow all packages at once:

#+begin_src sh
  cd ~/.dotfiles && stow aerospace bash emacs ghostty git helix homebrew npm pi tmux vim
#+end_src

Each package's directory structure is mirrored as symlinks in =~=.

Every top-level directory in this repo is a Stow package. Packages that also carry repo-local files, such as =pi/README.md=, exclude them from stowing with a =.stow-local-ignore= file in the package root.

** Bash

=.bashrc= sources every =*.bash= file in =~/.bashrc.d/=, and then every =*.bash= file in =~/.bashrc.d/private/=. Only the =private/= directory itself is tracked; its contents are ignored, so machine-local or sensitive shell configuration goes there.

** Emacs

The Emacs package loads a private file from =~/.private.el= at the end of =early-init.el=, before Elpaca is bootstrapped and before the main configuration. Keep machine-local or sensitive configuration there instead of tracking it in this repository.

Loading it there means it can override everything =early-init.el= sets, such as =default-frame-alist= or the pre-theme, and that the rest of the configuration can read values defined there, such as secrets or host-specific paths. The tradeoff is that the main configuration runs afterwards and is free to overwrite them, so package-specific customization should usually be wrapped in =with-eval-after-load=:

#+begin_src emacs-lisp
  (with-eval-after-load 'some-package
    ;; Private package-specific configuration.
    )
#+end_src

*** Tangling

=emacs/.config/emacs/config.org= is the source of truth for the main Emacs configuration. It tangles to =config.el=, which is generated, untracked, and should not be edited directly.

During startup, =init.el= loads =config.el= when it is newer than =config.org=. Otherwise it tangles =config.org= and loads the result.

Two commands are bound under the =C-,= leader for editing the config:

- =f c f= — ~my-edit-emacs-config~ opens =config.org=
- =f c r= — ~my-reload-emacs-config~ tangles =config.org= and reloads =config.el=

** Homebrew

macOS packages are managed with [[https://brew.sh/][Homebrew]]. The =homebrew= package provides:

- =.config/homebrew/Brewfile= — package list tracked via =brew bundle=
- =.config/brew-aliases/= — native Homebrew alias scripts (e.g. =brew i=, =brew ud=)
- =.local/bin/brew-visit= — external command to open a package's homepage in the browser

*** Brewfile

After stowing the =homebrew= package, =~/.config/homebrew/Brewfile= is a symlink back into this repo. =brew bundle --global= resolves the Brewfile via =$XDG_CONFIG_HOME= (set to =~/.config= in =.bashrc=), so no extra configuration is needed.

Dump currently installed packages:

#+begin_src sh
  brew bundle dump --global --force
#+end_src

Because =~/.config/homebrew/Brewfile= is a symlink, the dump writes directly to the tracked file. Review and commit the diff:

#+begin_src sh
  git diff homebrew/.config/homebrew/Brewfile
  git add homebrew/.config/homebrew/Brewfile && git commit
#+end_src

To install all packages on a new system:

#+begin_src sh
  brew bundle --global
#+end_src

See the [[https://docs.brew.sh/Brew-Bundle-and-Brewfile][brew bundle docs]] for details.

*** Brew aliases

Homebrew natively reads =~/.config/brew-aliases/= for alias scripts. The files in this repo are stowed there and become available as =brew <alias>=. Run =brew alias= to see the current list.

*** brew visit

=brew visit <package>= opens the first URL from =brew info <package>= in your browser. It is an [[https://docs.brew.sh/External-Commands][external brew command]] picked up automatically from =~/.local/bin/= (which is added to =PATH= in =.bashrc=).

*** brew needs-sudo

=brew needs-sudo= reports which outdated casks will likely prompt for =sudo= during =brew upgrade=, by inspecting install/uninstall artifact stanzas (=pkg= installers, sudo scripts, =pkgutil= uninstalls). Formulae are never checked, since Homebrew refuses to run them as root. It is an [[https://docs.brew.sh/External-Commands][external brew command]] picked up automatically from =~/.local/bin/=.

#+begin_src sh
  brew needs-sudo [--all] [--quiet] [--greedy]
#+end_src

- =--all= also lists casks that will *not* need sudo
- =--quiet= prints only tokens that definitely need sudo, for scripting
- =--greedy= passes =--greedy= to =brew outdated= (include auto-updating and =:latest= casks)

Exit status is 1 if any cask definitely needs sudo, else 0.
